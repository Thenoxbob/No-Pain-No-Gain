01 Qu'est-ce qu'un réseau informatique ?

Un réseau informatique est un ensemble de machines (ordinateurs, serveurs, smartphones, imprimantes...) interconnectées dans le but de partager des ressources et d'échanger des données. Ces connexions peuvent être filaires (câbles Ethernet) ou sans fil (Wi-Fi, Bluetooth).

Un réseau repose sur trois composantes fondamentales : les nœuds (les équipements), les liens (les connexions entre eux), et les protocoles (les règles de communication).

// concept clé
Un protocole est simplement un ensemble de règles que les machines suivent pour se comprendre — comme une langue commune entre équipements. 
# Ping basique pour tester une connexion réseau
$ ping 192.168.1.1
# Tracer la route d'un paquet
$ traceroute google.com
# Voir les interfaces réseau actives
$ ip addr show

03 Le Modèle OSI

Le modèle OSI (Open Systems Interconnection) découpe les communications réseau en 7 couches distinctes. C'est la colonne vertébrale de la compréhension des réseaux.

04 TCP/IP & protocoles essentiels

TCP/IP est le modèle réel utilisé sur Internet. TCP garantit la livraison des données via un handshake en 3 étapes. UDP est plus rapide mais sans garantie — idéal pour le streaming et les jeux en ligne.

# Le Three-Way Handshake TCP :
Client  → Server : SYN        # "Je veux me connecter"
Server  → Client : SYN-ACK    # "D'accord, je confirme"
Client  → Server : ACK        # "Connexion établie !"

# Ports importants à connaître
HTTP   : 80     | HTTPS  : 443
DNS    : 53     | SSH    : 22
FTP    : 21     | SMTP   : 25

05 Adressage IP

Chaque équipement réseau possède une adresse IP — son identifiant unique. Il existe deux versions : IPv4 (32 bits, ex: 192.168.1.1) et IPv6 (128 bits, ex: fe80::1).

Plage privéeNotation CIDRNb d'hôtesUsage
10.0.0.0/8~16 millionsGrands réseaux d'entreprise
172.16.0.0/12~1 millionRéseaux moyens
192.168.0.0/16~65 000Petits réseaux / maison
127.0.0.1—1Loopback (machine locale)
// subnet mask
Le masque de sous-réseau (ex: /24 = 255.255.255.0) détermine quelles adresses appartiennent au même réseau local. Maîtriser le subnetting est essentiel pour tout admin réseau.

Matériel Réseau

Comprendre les équipements physiques d'une infrastructure — de l'accès au cœur de réseau.

🔀
Switch (Commutateur)

Opère en couche 2 (OSI). Connecte les machines d'un même réseau local en utilisant les adresses MAC pour diriger les trames. Les switches managés permettent VLANs, QoS et spanning tree.

Couche 2 MAC VLAN
🌐
Routeur

Opère en couche 3 (OSI). Relie des réseaux différents et choisit le meilleur chemin pour acheminer les paquets IP. Essentiel pour la connexion à Internet et la segmentation de réseaux.

Couche 3 IP NAT
🛡️
Firewall

Filtre le trafic réseau selon des règles de sécurité. Peut être matériel ou logiciel. Les NGFW (Next-Gen Firewall) inspectent les paquets en profondeur (DPI) et gèrent les applications.

Sécurité DPI ACL
📡
Point d'accès Wi-Fi

Crée un réseau sans fil local (WLAN). Les standards actuels vont du Wi-Fi 5 (802.11ac) au Wi-Fi 6/6E (802.11ax). La gestion centralisée via WLC simplifie les déploiements d'entreprise.

802.11ax Wi-Fi 6
🖥️
Serveur

Machine dédiée à fournir des services : DNS, DHCP, fichiers, web, messagerie... Caractérisé par sa haute disponibilité, sa mémoire ECC et ses interfaces réseau redondantes (bonding).

DNS DHCP HA
🔌
Câblage & Médias

Les câbles Cat5e/Cat6/Cat6a supportent jusqu'à 10 Gbps. La fibre optique (monomode/multimode) permet des débits 100G+ sur de longues distances avec faible latence.

Cat6a Fibre SFP+

// pro tip
Les switches de couche 3 (L3) peuvent faire du routage inter-VLAN, ce qui réduit le besoin de routeurs dédiés dans les petites et moyennes entreprises.

Sécurité Réseau

Connaître l'attaque pour mieux défendre. Chaque vulnérabilité a une réponse — apprenez les deux.

01 Principales attaques réseau

Les attaques exploitent les failles des protocoles, des configurations ou du facteur humain. Voici les menaces à connaître absolument :

Phishing

Usurpation d'identité par email ou site frauduleux pour voler des identifiants.

Danger
90%

DDoS

Saturation d'un serveur par des milliers de requêtes simultanées via un botnet.

Danger
85%

Man-in-the-Middle

Interception de la communication entre deux parties pour écouter ou modifier les données.

Danger
75%

Ransomware

Logiciel malveillant qui chiffre les données et demande une rançon pour les restituer.

Danger
95%

ARP Spoofing

Corruption du cache ARP pour rediriger le trafic d'une machine vers l'attaquant.

Danger
65%

SQL Injection

Injection de code malveillant dans une requête SQL pour accéder à une base de données.

Danger
80%

02 Comment protéger un réseau

01

Segmenter avec des VLANs

Isoler les équipements par zones (RH, prod, invités) pour limiter la propagation d'une attaque latérale.

02

Configurer un Firewall strict

Règle par défaut : tout refuser. N'autoriser que ce qui est explicitement nécessaire — principe du moindre privilège.

03

Chiffrer les communications

TLS 1.3 pour le web, WPA3 pour le Wi-Fi, VPN IPsec ou WireGuard pour les accès distants sécurisés.

04

Monitorer avec un SIEM

Centraliser les logs et détecter les anomalies en temps réel. Outils : Splunk, ELK Stack, Wazuh.

05

Patcher régulièrement

90% des attaques exploitent des vulnérabilités connues avec un patch disponible. Mettre à jour sans exception ni délai.

Apprendre les Réseaux

Pas de méthode miracle. Un plan solide, des ressources sérieuses, et de la pratique quotidienne.

01 Feuille de route recommandée

1

Les bases absolues (1–2 mois)

Modèle OSI, TCP/IP, adressage IP, subnetting. Commencez avec "Computer Networking: Top Down Approach" (Kurose & Ross).

2

Pratique en lab (continu)

Packet Tracer de Cisco (gratuit) ou GNS3. Simulez des topologies, configurez des VLANs, testez des ACL et du routage.

3

Certification CompTIA Network+ (3–4 mois)

La certification de référence pour valider les bases réseaux sans prérequis constructeur. Reconnue internationalement.

4

Spécialisation Cisco CCNA ou autre (6 mois)

CCNA pour le routage/switching Cisco. JNCIA pour Juniper. Selon l'environnement cible.

5

Sécurité & Cloud (avancé)

CompTIA Security+, AWS/Azure Networking, CCNP Security. Le marché demande des profils hybrides réseau + cloud + sécurité.
